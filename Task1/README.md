-   внутренние данные,
-   конфиденциальные данные,
-   секретные данные.

-   обесценивание данных.

-   фонд недвижимости
-   данные о запланированных работах в рамках капитального ремонта

Внутренние данные

-   информация об устройствах умного дома
-   информация о сделках по недвижимости (осмотры)
-   информация о бизнес-процессах компании

Конфиденциальные данные

-   персональные данные собственников
-   информация о развитии IT-продуктов компании

Секретные данные

-   информация о сделках по недвижимости (сделки)
-   платежные данные по ЖКХ

---

Утечка данных

-   персональные данные собственников (критический, персональные данные имеют высокую ценность для мошенников, нарушение 152-ФЗ)
-   информация об осмотрах недвижимости (значительный, репутационная составляющая)
-   информация о сделках по недвижимости (критический, финансовые данные имеют высокую ценность для мошенников и недобросовестных конкурентов, нарушение 152-ФЗ)
-   платежные данные по ЖКХ (критический, персональные данные имеют высокую ценность для мошенников)
-   информация об IT-продуктах и бизнес-процессах компании (значительный, репутационная составляющая)

Потеря данных

-   фонд недвижимости (критический, напрямую влияет на бизнес-процессы компании, прямые финансовые потери)
-   персональные данные собственников (критический, финансовые и репутационные потери, нарушение 152-ФЗ)
-   информация о сделках по недвижимости (осмотры, сделки) (осмотры - значительный, сделки - критический)
-   платежные данные по ЖКХ (критический, финансовые и репутационные потери, нарушение 152-ФЗ)

Искажение данных

-   информация о сделках по недвижимости (осмотры) (значительный, репутационные потери, возможные финансовые потери при оформлении сделок)
-   фонд недвижимости (значительный, репутационные потери, возмоджные финансовые потери при оформлении сдело)
-   информация об устройствах умного дома (значительный, нарушение работы устройств умного дома, репутационные потери)

Некачественные данные

-   фонд недвижимости (значительный, репутационные потери)
-   данные о запланированных работах в рамках капитального ремонта (незначительный, не влияет на финансы)

Обесценивание данных

-   фонд недвижимости (значительный, репутационные потери, возможные финансовые потери)
-   данные о запланированных работах в рамках капитального ремонта (незначительный)
